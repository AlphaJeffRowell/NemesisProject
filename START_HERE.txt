================================================================================
                    NEMESIS PROJECT — START HERE
================================================================================

Welcome! This is a complete, automated Asana integration system for syncing
meeting notes to Asana tasks with auto-detection (no special syntax required).

================================================================================
                              QUICK START (3 STEPS)
================================================================================

Step 1: ONE-TIME INFRASTRUCTURE SETUP
-------------------------------------
Run this ONCE on your machine to set up Python and dependencies:

    cd C:\Repo\NemesisProject
    .\scripts\setup-infrastructure.ps1

(Takes ~5 minutes. Follow on-screen prompts.)


Step 2: CREATE YOUR FIRST CLIENT PROJECT
-----------------------------------------
Run this to create a new client project (e.g., Project-TWG):

    .\scripts\create-new-project.ps1

(Prompts you for: Client Name, Phase, Asana GID, Token, Folder Pattern)
(Creates all files and folders automatically)


Step 3: START WRITING NOTES
----------------------------
Drop notes into your project's "08 - Meeting Notes" folder.
They sync to Asana automatically!

    c:\Repo\Projects\Project-<Client>\Phase <N>\08 - Meeting Notes\

================================================================================
                              KEY FEATURES
================================================================================

✓ AUTO-DETECTION
  Write naturally: "Bloomberg integration complete"
  System finds: "Bloomberg Integration #27" and syncs automatically

✓ BACKWARD COMPATIBLE
  Explicit @task syntax still works and takes priority:
  @task search:"Task Name"

✓ MULTI-USER
  Each user has personal ASANA_PAT (never shared or committed)

✓ CLAUDE CODE HOOKS
  File saved → Sync happens automatically

✓ FUZZY MATCHING
  Confidence scoring disambiguates multiple matches

✓ ZERO MANUAL SETUP
  Scripts automate everything — no file editing needed
