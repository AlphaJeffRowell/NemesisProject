# Meeting Notes

This section contains meeting notes and discussions.

## Auto-Sync to Asana

Notes in this folder automatically sync to Asana tasks. Write naturally:

```
Bloomberg integration testing complete.
```

This automatically syncs to the Bloomberg task.

## Contents

- Client meetings
- Internal team meetings
- Steering committee notes
- Daily standups
- Review notes
- Decision logs

## File Organization

Create subfolders as needed:
- Meeting Notes/Client Meetings/
- Meeting Notes/Internal/
- Meeting Notes/Steering Committee/

## Getting Started

Start dropping meeting notes here. Files are auto-detected and synced to Asana.
